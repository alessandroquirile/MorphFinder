# MorphFinder

MorphFinder is a Python library for studying and exploring finite algebraic structures.

It provides a modular and extensible framework for:

- verifying algebraic axioms,
- modeling algebraic structures,
- discovering morphisms between structures using optimized backtracking algorithms.

Currently supported algebraic structures include:

- Magmas
- Semigroups
- Monoids
- Groups
- Rings
- Commutative Rings
- Unital Rings
- Fields
